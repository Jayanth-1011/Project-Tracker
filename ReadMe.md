# 🗂️ Task Management System

A full stack task management system with user authentication, task tracking, team collaboration, filtering, and more. Built with:

- **Frontend**: Next.js
- **Backend**: Node.js (Express or NestJS)
- **Database**: MongoDB or PostgreSQL

---

## 📁 Project Structure

/project-root
├── frontend/ # React.js frontend
└── backend/ # Node.js backend (Express)


---

## 🚀 Features

### ✅ Core Features
- User authentication (signup/login)
- Create, update, delete tasks
- Create and manage projects
- Filtering and status update of tasks
- Responsive UI

### 🌟 Optional Features (if implemented)
- Role-Based Access Control (RBAC)
- Real-time updates via WebSockets
- Recurring tasks
- Notification system
- Audit logs
- PWA support
- Unit & integration testing
- Task analytics

---

## 🔧 Tech Stack

| Frontend        | Backend            | Database       |
|----------------|--------------------|----------------|
| ReactJs         | Express      | MongoDB/PostgreSQL |
| Tailwind CSS    | JWT Auth            | Mongoose |

---

## ⚙️ Setup Instructions

### 📦 Prerequisites
- Node.js ≥ 16.x
- MongoDB/PostgreSQL installed
- Git

---

### 🚨 Environment Variables

#### `backend/.env`
PORT=5000
DATABASE_URL=your_database_connection_string
JWT_SECRET=your_jwt_secret


### ▶️ Running the Project

cd backend
npm install
npm run dev

cd frontend
npm install
npm run dev
